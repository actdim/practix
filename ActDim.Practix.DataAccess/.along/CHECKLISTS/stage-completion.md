# Mandatory Stage Completion Checklist

1. [ ] Automated tests, linting, and builds run with quiet flags.
2. [ ] All completed issues moved to `ISSUES/done/` with `status: done` and `completed: YYYY-MM-DD`.
3. [ ] Related milestone progress percentage updated.
4. [ ] Active session log written to `SESSIONS/`.
5. [ ] ISSUES board updated and lean.
6. [ ] Documentation in `docs/` updated if interfaces changed.
7. [ ] Prompt user to compact session (`/compact`).
